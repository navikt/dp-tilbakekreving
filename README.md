# Dagpenger-tilbakekreving

Tjeneste som lytter på fagsysteminfo-behov for tilbakekreving, slår opp behandlingsdata i
dp-behandling og svarer med fagsysteminfo på Kafka-rapiden.

## Komme i gang

Gradle brukes som byggverktøy og er bundlet inn.

`./gradlew build`
